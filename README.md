# orbit
Orbit is a chatting application which extends beyond general use chat apps by integrating better interactivity.


The vision behind the building of orbit as a major project is mainly for portfolio building but also to potentially grab users out of the classic layouts and chat groups.

Orbit aims to solve these issues by integrating a more emotionally and visually appealing design and features.

it is more of a ui/ux addition to classic chatting applications but will also require huge backed processing.
